#  Web MP3 Player (v1)

A sleek web mp3 player which is made using simple html, css and javascript. It is lightweighted web based simple mp3 player...
There is something that is you need to select and add music to the player 
---

##  Features

- **Core Playback Controls:** Play, pause, skip to the next track, and return to the previous track.
- **Progress Bar:** Interactive track timeline allowing users to seek/scrub through songs smoothly.
- **Volume & Mute Control:** Easily adjust volume levels or mute audio.
- **Playlist / Song Queue:** Browse and select tracks from a clean track list.
- **Responsive Design:** Fully optimized for desktop, tablet, and mobile browsers.
- **Clean UI/UX:** Minimalist layout built for distraction-free listening.

---

##  Tech Stack

- **HTML5:** Semantic markup and `<audio>` API integration.
- **CSS3:** Modern styling, flexbox/grid layout, and responsive media queries.
- **JavaScript (Vanilla):** Audio event handling, playlist management, and UI state updates.
